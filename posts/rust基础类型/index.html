固定位数的类型

整数类型

大小 无符号整数 有符号整数 浮点数
8 u8 i8  
16 u16 i16  
32 u32 i32 f32
64 u64 i64 f64
128 u128 i128  
机器字 usize isize  

Rust使用u8类型表示一个字节的值。从二进制文件或者套接字中读取数据就会返回u8类型的数据流。

与C和C++不同的是，Rust区分流字符和数字类型：char不是u8，也不是u32，是一个单独的类型

usize和isize与目标机器上的地址空间的位数相同。如32位架构上就是32位，64位架构上就是64位。

Rust要求数组的索引为usize类型。包括vector和其他任何含有多个元素的数据结构的长度都是usize。

整数的字面量可以使用一个后缀来指示类型。如42u8表示的就是一个u8类型的值，1792isize就是表示一个isize类型的值，如果没有后缀指示，那么就由Rust推导类型。

前缀0x，0o，0b分别表示十六进制、八进制、二进制的字面量。

可以在数字中间插入下划线来使它更可读。如0xffff_ffff，123_456_789。

Rust还提供来字节字面量

Checked、Wrapping、Saturating、Overflowing

当整数运算溢出的时候，在debug模式下，程序会panic。在release模式下，运算结果会回环（可能导致死循环等异常）。

如果默认行为不是希望的结果，整数类型提供来一个方法可以指定做什么。

  • Checked操作返回一个结果的Option值：如果能正确处理，返回Some(v)，否则返回None。
assert_eq!((10_u8).checked_add(20), Some(30));
assert_eq!((100_u8).checked_add(200), None);
  • Wrapping操作返回正确的值相对结果类型能表示的范围的余数
assert_eq!((100_u16).wrapping_mul(200), 20000);
assert_eq!((500_u8).wrapping_mul(500), 53392);

/* 有符号数的操作可能回环成负数 */
assert_eq!((500_i16).wrapping_mul(500), -12144);

// 移位操作中，移动的位数会回环成该类型的位数之类
// 对16位的数字移动17位，等于移动1位
assert_eq!((5_i16).wrapping_shl(17), 10);
  • Saturating操作会返回最接近结果的表示。即截断到这个整数类型能表示的最大、最小值
assert_eq!((32760_i16).saturating_add(20), 32767);
assert_eq!((-32760_i16).saturating_sub(10), -32768);
  • Overflowing操作会返回一个tuple(result, overflowed)，其中result是回环版本的方法返回的结果，overflowed是一个指示是否发生溢出的bool值
assert_eq!((255_u8).overflowing_sub(2), (253, false));
assert_eq!((255_u8).overflowing_add(2), (1, true));

浮点数

Rust提供IEEE的单精度和双精度的浮点数。这两个类型还包括正无穷、负无穷、正0、负0和非数值

Rust把整数字面量和浮点数字面量区分为不同的类型：从来不会把一个浮点数类型推导为整数类型，反之依然。

字面量 类型 数值
-1.4625 自动推导 -1.4625
2. 自动推导 2
0.25 自动推导 0.25
1e4 自动推导 10000
40f32 f32 40
9.109_383_56e-32f64 f64 一个小数

f32和f64还关联来特殊常量值，如正无穷(INFINITY)\负无穷(NEG_INFINITY)\非数值(NAN)\最大值(MAX)\最小值(MIN)

注意, 方法的调用优先级高于前缀运算符, 因此对负数调用方法时要用括号括起来

assert_eq!((-1.01f64).floor(), -2.0)

std::f32::consts和std::f64::consts模块提供了常用的数学常数，例如E、PI、2的平方根。

Rust几乎不允许隐式的类型转换，不同将i32的值传递给f64，甚至不允许从i16到i32的隐式转换。但可以通过as运算符来进行显示的转换：i as f64或x as i32

布尔类型

Rust的布尔类型只有两个值。true和false。比较运算符会产生bool类型

Rust里不能隐式的把字符、整数、浮点数或指针等类型转换为布尔值，必须是bool表达式。不能写出if x { ... }

可以通过as运算符将bool转成整数值，但是反过来不行，必须显式的写出比较运算符

assert_eq!(false as i32, 0);
assert_eq!(true as i32, 1);

// 不行
assert_eq!(0 as bool, false);

Rust中使用整个字节表示bool，因此可以创建指向它的指针

字符

Rust字符类型char代表一个单独的Unicode字符，是一个32位的值。Rust使用char表示单个字符，但使用UTF-8编码字符串和文本流，因此String表示它的文本数一个UTF-8字节序列，而不是字符的数组 字符字面量是一个被单括号包围的单个字符，例如'8'或'|'。可以使用Unicode范围内的任何字符。 Rust永远不会进行char和其他任何类型之间的隐式转换，可以使用as转换运算符来把char转换成整数类型，对于小于32位的类型，字符值的高位会被截断

assert_eq!('*' as i32, 42);

u8是为一个可以用as运算符转换成char的整数类型。

Rust只会对开销很低且不可能失败的转换使用as运算符

任何u8之外的整数类型值转换时需要运行时检查。所以，标准库中提供了函数std::char::from_u32接受任何u32的值，并返回Option<char>，如果不是合法的Unicode码点，会返回None，否则会返回Some(c)，c就是转换结果的char

标准库中还为字符类型提供来一些有用的方法。is_alphabetic(), to_digit(), from_digit(2, 10)

元组

元组是多个不同类型的值的组合，可以将元组看作被逗号分割和括号包围的元素序列。元组中的元素不需要是相同的类型

元组只允许常数索引，不能通过变量来获取元素

Rust代码中经常使用元组类型来返回多个值。

可以将元组视为一种极简的结构图类型。

元组的另一个常见用法数0元组()，通常被称为单元类型。如没有返回值的函数，实际就是返回的0元组。

指针

Rust中有几个表示内存地址的类型。默认情况下Rust里的值数嵌套的，值((0,0), (1440,900))被存储为四个相邻的整数。如果把它赋值给一个局部变量，那么会得到一个4个整数大小的局部变量，不会值对上分配任何内存。 这导致当Rust程序需要指向其他值的指针时，必须显示的使用指针类型。
